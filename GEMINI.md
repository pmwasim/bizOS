# GEMINI.md

The operating instructions for every AI agent working on bizOS live in one place:
**[AGENTS.md](AGENTS.md)**. Read it in full before touching the repository.

This file is a pointer, not a copy, so that Gemini CLI and Antigravity land on the same protocol as
every other agent. More than one agent may be working here at the same time — claim before you edit
(`pnpm agent:claim`), open a journal entry when you start (`pnpm journal:new`), and release when you
finish (`pnpm agent:release`). The rationale is in
[docs/multi-agent-protocol.md](docs/multi-agent-protocol.md).
