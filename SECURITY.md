# Security policy

## Supported versions

bizOS is pre-release. Only the latest commit on `main` receives security fixes; no production
version is currently supported.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** private reporting flow for this repository. If that flow is
unavailable, contact the repository owner privately through their verified GitHub profile.

Include:

- affected revision and component;
- reproducible steps or a safe proof of concept;
- impact and required preconditions;
- suggested mitigation if known.

Do not open a public issue, access data that is not yours, degrade service, persist access, or
include secrets or personal data in the report.

The team will acknowledge a complete report within three business days, provide a triage update
within seven business days, and coordinate disclosure after a fix or mitigation is available.
Timelines may change with severity and complexity, but the reporter will receive an explanation.
